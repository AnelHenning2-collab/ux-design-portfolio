# UX / Design Portfolio

This repository showcases selected UX and interface design work, including prototypes, flows, and design systems.

## About this repository

- **Focus:** UX / Design
- Contains: Wireframes, interactive prototypes, user flows, design systems, and supporting documentation.
- Audience: UX and product hiring managers, collaborators, and reviewers interested in my design process.

## Highlights

- End‑to‑end flows that connect user goals to interface decisions and information architecture.
- Design system elements (colors, typography, components) aligned with accessibility and clarity.
- Case studies that explain the problem, constraints, iterations, and final design choices.

## Repository structure

- `/docs` – Case studies, design rationales, and write‑ups.
- `/wireframes` – Low‑fidelity sketches and early explorations.
- `/prototypes` – Higher‑fidelity screens or links to interactive prototypes.
- `/systems` – Style guides, component libraries, and design tokens (where applicable).

## How to view this work

- Start in `/docs` to read one or two case studies that interest you most.
- Review `/wireframes` and `/prototypes` together to see how ideas evolved over time.
- Explore `/systems` to understand how I approach consistency, accessibility, and scalability.

## Tools and technologies

- Collaboration and documentation: GitHub, exported screens, and Markdown case studies.
